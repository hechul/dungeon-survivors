# AI Game to Apps in Toss 7-Day Template

This template applies to AI-generated game prototypes that already have a runnable web or browser-based game foundation.

## Day 1: Intake and Diagnosis

- Create GitHub repository
- Commit original AI-generated source
- Confirm the game runs
- Identify stack and project structure
- Understand genre and core rules
- List major features
- Identify critical bugs and structural risks
- Estimate Apps in Toss conversion scope

## Day 2: Core Structure Cleanup

- Create feature/fix branches
- Stabilize entry, gameplay, result, and restart flow
- Clean input handling
- Clean event/state handling
- Confirm save-data structure
- Make the basic game loop playable without interruption

## Day 3: Major Bug Fixes

- Fix progression-blocking bugs
- Fix scene-transition issues
- Fix save/load issues
- Fix mobile-control issues
- Remove console errors
- Run repeated play tests
- Merge reviewed PRs into `main`

## Day 4: Apps in Toss Conversion

- Apply Apps in Toss WebView structure
- Add Apps in Toss SDK/configuration
- Configure app entry, name, and icon
- Confirm production build structure
- Confirm static asset paths
- Generate an Apps in Toss test build

## Day 5: Mobile and App QA

- Test iOS and Android screen ratios
- Test touch, swipe, and button controls
- Test back, pause, restart, and resume flows
- Test background/foreground behavior
- Test sound on/off behavior
- Test save persistence
- Test sandbox and QR flow

## Day 6: Gameplay and UX Improvement

- Improve the first playable minutes
- Tune difficulty, rewards, speed, and pacing
- Improve UI readability
- Adjust button size and touch areas
- Improve result/restart motivation
- Apply internal QA feedback

## Day 7: Submission Candidate

- Prepare app icon
- Prepare screenshots
- Write app description
- Write game guide and caution text
- Check submission checklist
- Create submission candidate build
- Tag release in GitHub
- Prepare Apps in Toss submission

## Schedule Buffer

Default estimate is 7 business days. Depending on game complexity, original code quality, asset readiness, and Apps in Toss integration scope, the schedule can vary by about plus or minus 2 to 3 business days.
